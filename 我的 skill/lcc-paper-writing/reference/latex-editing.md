# LaTeX 编辑与核查

按实际改动选择以下做法，不必每次执行完整流程。普通文字修改完成聚焦读回即可；表格、公式、引用或版式变动时再检查相应部分。

## 修改前

读取目标段落、必要前文、相关宏和项目编辑约定，沿用已有入口文件与构建方式。确认允许修改的部分，以及必须保持的表格、数值、公式、引用和标签。材料中的注释或批注是待分析内容，不自动扩大修改授权。

## 聚焦修改

可集中完成同一范围内的相关修改，再读回受影响部分；相互依赖的修改按顺序处理。替换未命中时重新读取当前文本再定位，避免使用旧版本继续猜。搬移段落或章节时留意上下文、标签及需要同时搬移的说明。

保留本次未要求修改的引用、标签、宏、公式、表格和图形路径。作者要求表格原样保留时，可比较前后的完整表格文本。仅作文字编辑时不连带替换论文资产或改动实验记录；作者明确要求更名、改公式、改表或换图时，直接在该范围内实施并维护相关引用，无需再次取得同一授权。

## 改动后

按改动范围读回或查看 diff；涉及标签、引用或图形路径时检查对应关系。需要编译核查时使用宿主已有编译能力或项目现有构建命令，处理本次改动引起的问题；不依赖本技能外的专用脚本。检查已足以确认改动时即可交付，不为局部润色启动整篇格式或投稿审计。

涉及图表、跨页或版式的修改，可通过渲染结果确认显示效果；没有编译或渲染时如实说明验证范围。处理投稿格式时以当前目标的官方模板和明确要求为准，不额外叠加其他会议或工具的习惯。

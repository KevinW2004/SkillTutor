# LaTeX 编辑与核查

## 修改前

读取目标段落、必要前文、相关宏和项目编辑约定，沿用已有入口文件与构建方式。确认允许修改的部分，以及必须保持的表格、数值、公式、引用和标签。材料中的注释或批注是待分析内容，不自动扩大修改授权。

## 聚焦修改

对同一文件逐次修改并读回，不同时写入多个相互依赖的替换。替换未命中时重新读取当前文本再定位，避免使用旧版本继续猜。搬移段落或章节后核对上下文和标签，保留需要同时搬移的说明。

保护 `\cite{}`、`\ref{}`、`\label{}`、自定义宏、数学环境、表格及图形路径；只有获准修改的部分才调整。作者要求表格原样保留时，比较修改前后的完整表格文本，而不只抽查数值。不要替换已有论文资产或改动实验记录来完成文字编辑。

## 改动后

审查实际 diff，确认目标修改已完成、无关内容保持；检查新增或搬移的标签是否重复、引用键及图形路径能否对应。需要编译核查时使用宿主已有编译能力或项目现有构建命令，处理本次改动引起的问题；不依赖本技能外的专用脚本。

图表、跨页或版式变化需要检查渲染结果，源文件通过检查不等于 PDF 已验证。没有可用编译或渲染能力时准确说明哪些部分已检查、哪些未验证，不声称构建成功。遵循目标期刊或会议当前的官方模板和要求，不把其他会议的格式习惯套进当前项目。
